# HTTP API 服务器使用文档

## 🚀 启动方式

### 方式 1: 使用启动脚本（推荐）

```bash
cd /work/workspace/solana_worspace/pump-fun-plugin/backend/rust_backend
./run_with_api.sh
```

### 方式 2: 使用环境变量

```bash
cd /work/workspace/solana_worspace/pump-fun-plugin/backend/rust_backend
ENABLE_HTTP_API=true cargo run --bin rust_backend
```

### 方式 3: 仅启动 HTTP 服务器

```bash
cd /work/workspace/solana_worspace/pump-fun-plugin/backend/rust_backend
cargo run --bin http_server
```

## 📋 API 端点

服务器默认运行在: `http://0.0.0.0:3000`

### 1. API 信息
```bash
GET http://localhost:3000/
```

### 2. 健康检查
```bash
GET http://localhost:3000/health
```

### 3. 获取所有事件
```bash
GET http://localhost:3000/api/events
```

响应示例:
```json
{
  "success": true,
  "data": [...],
  "error": null,
  "total": 10
}
```

### 4. 获取最近的 N 条事件
```bash
GET http://localhost:3000/api/events/recent/10
```

### 5. 统计事件总数
```bash
GET http://localhost:3000/api/events/count
```

响应示例:
```json
{
  "success": true,
  "data": 100,
  "error": null,
  "total": null
}
```

### 6. 根据 mint 查询事件
```bash
GET http://localhost:3000/api/events/mint/{mint_address}
```

示例:
```bash
GET http://localhost:3000/api/events/mint/HZWKVfammvEHaNfPnYTppEgXYppZWfqPiGgxwgAjEdVv
```

### 7. 根据创建者查询事件
```bash
GET http://localhost:3000/api/events/creator/{creator_address}
```

示例:
```bash
GET http://localhost:3000/api/events/creator/CjisaxtyK4n43PBhCATyydWQU93ruN1KJTRkcEhkGVyR
```

## 🧪 测试 API

### 使用 curl
```bash
# 获取所有事件
curl http://localhost:3000/api/events | jq '.'

# 获取最近 5 条事件
curl http://localhost:3000/api/events/recent/5 | jq '.'

# 统计总数
curl http://localhost:3000/api/events/count | jq '.'
```

### 使用浏览器
直接在浏览器中打开:
- http://localhost:3000
- http://localhost:3000/api/events
- http://localhost:3000/api/events/recent/10

## ⚙️ 配置

HTTP API 功能通过环境变量 `ENABLE_HTTP_API` 控制:
- `ENABLE_HTTP_API=true` - 启用 HTTP API（同时运行事件监听器）
- `ENABLE_HTTP_API=false` 或不设置 - 仅运行事件监听器

## 🔧 数据库配置

HTTP API 使用与主程序相同的数据库配置，在 `config.yaml` 中配置:

```yaml
database:
  type: sqlite  # 或 mysql, postgres
  sqlite_path: data/events.db
  max_connections: 5
  min_connections: 1
```

## 📦 功能特性

- ✅ CORS 支持（允许所有来源）
- ✅ JSON 响应格式
- ✅ 错误处理
- ✅ 分页支持
- ✅ 统一的响应结构
- ✅ 实时数据（直接从数据库读取）

## 🎯 使用场景

1. **前端应用**: 在 Web/Mobile 应用中调用 API 展示事件数据
2. **数据分析**: 使用 curl/Python 脚本获取数据进行分析
3. **监控面板**: 构建实时监控仪表板
4. **第三方集成**: 允许其他系统访问事件数据
