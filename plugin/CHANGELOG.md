# Changelog

All notable changes to the Pump.fun Pledge Tracker extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-01

### Added
- Initial release of Pump.fun Pledge Tracker
- Real-time pledge status tracking for meme coins
- Color-coded badges (pledged/not pledged/unknown/error)
- Interactive tooltips with detailed risk information
- Centralization risk percentage display
- Promotional banner with call-to-action
- Shadow DOM integration for style isolation
- Batch API requests for optimal performance
- Automatic DOM scanning every 5 seconds
- MutationObserver for dynamic content detection
- Comprehensive documentation (README.md, DEVELOPMENT.md)
- TypeScript support throughout
- Tailwind CSS styling
- React-based UI components
- Manifest V3 compliance

### Technical Details
- Built with React 18.2
- Vite build system
- TypeScript 5.2
- Tailwind CSS 3.3
- Chrome Extension Manifest V3
